Anton Agafonov

I'm an AI Engineer and Team Lead at Bosch Corporate Research, developing multimodal, perception-based policies for real-time robotic systems. I translate scene understanding into actionable outputs for autonomous decision making, leveraging state-of-the-art models including diffusion-based policies and Vision-Language-Action (VLA/VLM) models. I built a multimodal vision-action diffusion policy from scratch, featuring attention-based perception encoders that fuse proprioception with dual egocentric camera data for real-time robotic manipulation and assembly. I have adapted foundation VLA models (SmolVLA, Pi0.5) through targeted dataset collection and fine-tuning using open-source frameworks. My work includes developing real-time algorithms for 6D pose estimation from mono-RGB input, integrating advanced vision models (SAM2, MegaPose) into scalable industrial workflows. I stay continuously up-to-date with recent research in multimodal AI and robotics, ensuring my work incorporates the latest advancements. My multidisciplinary background in both AI and Mechanical Engineering R&D provides a unique systems-level understanding, enhancing my contributions to the team.

STMPL: Human Body Soft Tissue Deformation Deep Learning Simulation
M.Sc Research Thesis, Technion, 2024
Project Page  /  Paper

Developed the STMPL model, an enhanced version of the SMPL model for realistic simulation of human soft tissue deformations optimized for real-time applications. The model maps 3D body data to 2D UV maps for efficient processing using a UNET-based architecture, achieving real-time inference speeds of 2ms with FEM-level accuracy while generalizing on unseen shapes and thicknesses.

Autonomous Car - Jetson Xavier NX
ROS2-based Autonomous Vehicle Project
Github  /  Original Version  /  Video

Comprehensive autonomous vehicle project built with ROS2 Foxy on NVIDIA Jetson Xavier NX, transforming a basic RC car into an intelligent autonomous vehicle with real-time control and expandable architecture.

Key Features:

  • Hardware Platform: NVIDIA Jetson Xavier NX for high-performance edge computing with differential drive motor control
  • ROS2 Architecture: Modular design using ROS2 Foxy with clean package structure for easy expansion and development
  • Manual Control: Bluetooth joystick teleoperation with Xbox/PS4 controller support and customizable control mapping
  • Safety Systems: Emergency stop functionality, speed limiting, mode switching, and comprehensive safety protocols
  • Real-time Performance: Low-latency control loop for responsive driving with hardware PWM control
  • Future Integration: Planned camera integration, lane detection, autonomous navigation, and obstacle avoidance capabilities

Technical Implementation: The system uses precise PWM-based differential drive control, comprehensive parameter configuration, and robust command routing with topics for joystick input, manual control commands, and final motor commands.
Bitcoin Blockchain Simulation
Blockchain Technology Demo
Demo

A toy example of a Bitcoin Blockchain Simulator designed to be an interactive and educational web application. It visually demonstrates the fundamental principles of a cryptocurrency network with multiple nodes.

Key Features:

  • 🌐 Multi-Node Network : Simulates a network of nodes, visually representing their positions and connections. Users can add new nodes to see how the network expands.
  • 💰 Wallet & Transaction Management : Allows users to create new wallets, view balances, and send transactions between them. The simulation shows pending transactions in a mempool before they are confirmed in a block.
  • ⛏️ Proof-of-Work Mining : A mining process is simulated where a random node attempts to solve a cryptographic puzzle to create a new block. The successful miner receives a block reward and transaction fees.
  • ⛓️ Blockchain & Block Details : Nodes maintain their own copy of the blockchain. Users can inspect any node's blockchain to see the details of each block, including its hash, transactions, and the miner's nonce.
  • ⚙️ Dynamic Controls : Users can manually create transactions and start the mining process, or enable an auto system to run the simulation automatically. Controls for adjusting mining difficulty and network height are also available.
